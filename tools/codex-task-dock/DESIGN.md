# Task Dock 设计说明

## 方向

采用用户确认的方案 B：上方是一条明确的当前焦点任务，下方是扁平任务队列。界面以冷白和浅灰为主，仅把颜色用于任务语义，不设置添加入口，不使用渐变、玻璃拟态或多层卡片。

任务汇总区提供“一键开发全部”批量操作。空闲时使用青绿浅底强调可执行性；队列运行时原位切换为“停止后续任务”，并明确展示完成数、失败数和剩余数，避免新增独立工具栏挤压任务列表。

## 视觉系统

- 字体：Windows 系统 UI 字体，任务 ID 与补丁使用等宽字体。
- 主操作：低饱和青绿色，强调“交给 Codex”。
- 待开发：琥珀黄；已完成：绿色；开发中：青绿；漂移或失败：红色。
- 圆角：焦点容器 12px，控件 8px；其余任务使用分隔线维持密度。
- 交互目标最小高度 44px，所有操作支持键盘焦点，弹窗使用原生 `dialog`。

## 自适应规则

面板宽度根据 Codex 窗口宽度在 320px 至 420px 之间变化。Codex 左侧有空间时停靠在窗口外侧；窗口最大化或左侧空间不足时，面板覆盖在 Codex 左缘。高度始终跟随 Codex，Codex 最小化时面板隐藏，切换到其他应用时取消置顶。

窄宽度会压缩左右边距并隐藏非关键同步说明；低高度会收紧焦点区域并隐藏次要安全说明，任务列表继续占用剩余滚动空间。
