# Codex Task Dock

Task Dock 是独立于旅行规划业务的 Windows 桌面辅助工具。它把 `docs/Dev/task*.md` 中的开发任务显示为 Codex 左侧的浅色任务面板，并让每条任务拥有可验证的开发、完成、漂移与回退状态。

## 启动

在 PowerShell 中运行：

```powershell
.\tools\codex-task-dock\start.ps1
```

需要查看控制台诊断时：

```powershell
.\tools\codex-task-dock\start.ps1 -Console
```

工具仅依赖 Python 3.11、Git、Microsoft Edge 与本机 Codex CLI，不安装额外 Python 包。运行状态、补丁、隔离 worktree 与日志位于 `%LOCALAPPDATA%\CodexTaskDock\<项目标识>`，不会写入业务数据库。

## 任务来源与同步策略

- 唯一任务来源是 `docs/Dev/task*.md`，文件名以 `_done` 结尾的归档会跳过。
- 每 3 秒只读取目录元数据和已知文件的 `mtime + size`。
- 只有指纹变化的文件才重新打开与解析。
- 仅当目录 `mtime` 变化时重新枚举文件，并每 60 秒执行一次兜底枚举。
- 面板没有“添加任务”入口，新增任务应继续由项目文档工作流产生。

## 状态筛选

- “其他任务”右上角的状态筛选默认显示“全部状态”。
- 可选“待开发”“开发中”“已完成”或“需检查”；筛选只改变当前列表显示，不修改任务文档或任务状态。
- 当前焦点任务始终保留在上方，方便在筛选列表时继续查看或操作。

## 状态与安全边界

- 黄灯：代码补丁尚未存在，可以交给 Codex。
- 青灯：Codex 正在隔离 worktree 中开发，同时只运行一条任务。
- 绿灯：任务补丁可被 Git 完整反向校验，证明对应代码当前存在。
- 红灯：文档、提交或补丁与当前代码不一致，工具停止自动覆盖。
- Revert 只反向应用这一条任务的独立补丁；校验不通过时拒绝执行。
- 删除只移除开发任务文档中的对应记录，不改变代码，并在写入前校验源行签名。
- “一键开发全部”会把当前所有黄灯任务按列表顺序加入队列，仍然一次只运行一个隔离 worktree；停止队列只取消尚未开始的任务，不强制终止当前 Codex。

Codex 运行前会把当前未提交文件复制到临时 worktree 并生成上下文快照，所以它能看到真实项目状态。任务补丁以该快照为基线，只包含本次任务新产生的改动。

每次开发都会在状态目录的 `results/` 中原子写入运行回执，记录进程、日志、退出码、结果摘要与补丁路径。Codex 完成后，Dock 先接收并校验回执和补丁，再更新状态灯；如果 Dock 中途重启，会结合存活进程、JSONL 完成事件、隔离 worktree 和补丁恢复真实结果，不会永久停留在“开发中”。任务详情在完成后显示 Codex 返回的结果摘要。

任务详情中的“跳转到任务原文”会在 VS Code 中打开对应的 `docs/Dev` 任务文档，并跳转到任务标题所在行；服务端只允许打开扫描器已识别且仍位于该目录内的文件，并会确认 VS Code 已成功接收跳转命令后再反馈成功。
