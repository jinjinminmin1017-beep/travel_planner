7. 变体数量不超过配置上限，不出现无界席别组合。

2. MOST_COMFORTABLE 使用确定性舒适度、风险和成本排序；并列结果稳定。
3. BALANCED 只能从后端 Pareto 集选择；越权 plan_id 被拒绝。
4. 推荐理由、卡片、详情、费用明细和 selected seat 完全一致。
5. 可用计划不足时保持现有 NOT_AVAILABLE 语义，不复用失效计划补位。
